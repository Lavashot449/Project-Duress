# The Echoes

**Status: recovered HISTORICAL workflow and roster; full design corpus SOURCE MISSING.** Source: [S02, original README](../history/private-projectresonance/PROVENANCE.md).

The original Project Resonance README describes a Manifestation Studios creative project reimagining characters, encounters, weapons, environments, and rewards through a unified visual and narrative framework. Each completed Echo is built from **FORM, VOICE, POWER, BOONS, and DOMAIN**, then assembled into a final **Manifestation**.

Those component labels are preserved exactly. The README does not provide their full specifications, so this edition does not invent component contents or definitions.

## Recovered Echo entries

- [Riven — Echo of A Thousand Voices](riven.md)
- [Rhulk — Echo of the Deep](rhulk.md)
- [Nezarec — Echo of Nightmares](nezarec.md)

The old README calls those Echoes fully manifested and approved. That statement is preserved as historical provenance. Their complete visual designs, texts, encounters, component approvals, and final assets were not present in the recovered repository.

The [raid-boss Echo roster](raid-boss-roster.md) separates those three named entries from Atheon's appearance as a workshop example. It is not represented as the complete current roster.

“Echo” here names the creative subject. The current subclass terminology **Echo → Reverb** does not authorize renaming the Echo project, these titles, or archived text.

## Governing development flow recovered

The supplied [Rev Grimoire](../books-of-sorrow/rev-grimoire/2026-09-09/README.md), section 5, gives DOMAIN → VOICE → SHAPE → POWER → BOONS within the wider ritual flow. This differs from the older README's component naming/list. Both are preserved; FORM and SHAPE are not silently declared equivalent. See [the full flow](../continuity/ritual-and-archive-language.md). The Book does not provide the completed character dossiers or their assets.
